# Original artwork

Created with the built-in image-generation tool using a founder-provided style reference. The reference itself is not included in the repository. No stock-image subscription or paid asset purchase was used. Original compositions are preserved and compressed to WebP. CSS selects individual cells of the photographic sheets. Generated imagery is illustrative rather than evidence of a real event or person.
